## 아이디어 1. AI 선생님 교육 서비스

처음 제안한 아이디어는 교육 관련 서비스였다.

기존 교육 서비스인 콴다를 참고하여 아이디어를 기획했다.

현재 콴다는 프리미엄 코스를 결제하면 코인을 지급하고, 해당 코인을 사용하여 선생님에게 질문할 수 있는 방식이다.

하지만 질문 난이도에 따라 코인이 차감되는 구조이기 때문에 쉬운 문제는 3000코인, 중간 난이도는 4000코인, 어려운 문제는 5000코인 등 질문을 많이 할수록 비용 부담이 커지는 문제가 있다고 생각했다.

이를 해결하기 위해 사람 선생님 대신 AI 선생님을 활용하는 서비스를 생각했다.

AI 선생님을 통해 기존 선생님보다 더 많은 질문을 할 수 있고, 더 많은 문제를 분석하며 사용자에게 맞춤형 답변을 제공하는 아이디어였다.

하지만 인프런에서 비슷한 형태의 AI 교육 서비스가 이미 존재하는 것을 확인하여 해당 아이디어는 폐기하게 되었다.

---

## 아이디어 2. AI 기반 민원 분석 시스템

두 번째 아이디어로 공무원들의 민원을 AI가 분석하는 시스템을 제안했다.

구체적으로는 기존에 들어온 민원 데이터를 AI가 분석하여 비슷한 민원을 자동으로 그룹화하고, 유형별로 분류하는 시스템이다.

이를 통해 공무원들이 현재 어떤 문제가 많이 발생하고 있는지 쉽게 파악할 수 있도록 하는 것을 목표로 했다.

또한 특정 유형의 민원이 갑자기 증가하거나 위험 신호가 감지되는 경우 공무원에게 우선적으로 노출하여 새로운 사회 문제를 빠르게 발견하고 대응할 수 있도록 하는 기능을 생각했다.

하지만 팀원들과 논의한 결과 해당 아이디어도 진행하지 않기로 결정했다.

# 학습한 내용

이번 주에는 데이터 분석에 필요한 통계학 기초 내용을 학습했다.

학습한 내용은 다음과 같다.

- 평균의 종류
- 분산
- 표준편차
- 왜도
- 첨도
- 적률
- Z-score
- 대푯값
- 모수와 분포 형태에 따른 대푯값 관계
- 그래프 해석 방법

현재 프로젝트에서는 모델 학습에 필요한 데이터 수집과 데이터 전처리, LLM 관련 코드 정리 등의 역할을 수행할 수 있을 것으로 생각한다.

이를 개선하기 위해 이번 캡스톤 시간에는 이전보다 적극적으로 의견을 공유하고 팀원들과 대화하려고 노력했다.

그 결과 처음 캡스톤을 진행했을 때보다 팀원들과의 소통이 좋아졌다는 것을 느꼈고, 팀 프로젝트에서 효율적으로 의견을 공유하는 방법에 대해서도 조금씩 감을 잡을 수 있었다.

하지만 성현이가 음성 인식 분야를 경험해본 적이 없었고, 프로젝트 진행 가능성을 고려한 결과 소리눈 AI 아이디어도 진행하지 못하게 되었다.

아이디어에서 내가 맡을 수 있는 역할을 찾고 팀원에게 제안하려고 노력한 점은 잘했다고 생각한다.

하지만 팀원의 기술 경험과 프로젝트 구현 가능성을 더 빠르게 고려하지 못한 점은 아쉬웠다.
